# Security Policy / 安全策略

## Supported Version / 支持版本

Security fixes are provided for the latest Desktop build published in GitHub
Releases. / 安全修复仅面向 GitHub Releases 中最新发布的 Desktop 构建。

## Reporting a Vulnerability / 报告安全问题

Please use GitHub's **Report a vulnerability** private security-advisory flow.
Do not include API keys, credentials, private logs, workspace files, or other
personal data in a public issue.

请通过 GitHub 的 **Report a vulnerability** 私密安全公告功能报告漏洞。请勿在
公开 Issue 中提交 API 密钥、凭据、私人日志、工作区文件或其他个人数据。

This community project is not an official DeepSeek support channel. / 本社区
项目并非 DeepSeek 官方支持渠道。
